## Gate A — Parser survival

If a number lives only inside a PNG, it does not exist.

- [ ] Every metric in the deck also exists as selectable text or an appendix table.
- [ ] Charts have a caption and a raw-number table on the following slide or in the leave-behind.
- [ ] The PDF is text-selectable. Fonts are not outlined. Pages are not flattened scans.
- [ ] Reading order is top-to-bottom, left-to-right. No text boxes stacked as decoration.

## Gate B — Numbers a model can extract

Associates prompt: find TAM discrepancies and missing unit economics.

- [ ] TAM / SAM / SOM sit in a three-row table with the sizing method in the same table.
- [ ] Unit economics (gross margin, NRR or equivalent, payback or CAC logic) are in a table, not a spark-line.
- [ ] The ask, post-money, and months of runway are written as numerals in body text.
- [ ] Use of funds is a short table, not an icon row.

## Gate C — Claims vs evidence

The model treats a missing source as a missing business.

- [ ] Each headline claim names its source slide or data-room file.
- [ ] “AI-discovered / proprietary model / unique data” states train vs test split and what was wet-lab confirmed.
- [ ] Regulatory path names the first predicate (RUO, LDT, CDSCO, 510(k), PMA, IND) — not “we will get approved.”
- [ ] Competitive lines state the other company’s limit, not only your adjective.

## Gate D — Red-team FAQ

An FAQ slide is not an FAQ. These answers must live in a text document.

- [ ] Moat is written as a mechanism (IP, data loop, switching cost), not a slogan.
- [ ] Gross margin states what is inside COGS (compute, wet-lab, people).
- [ ] If you have a sales motion: CAC components are listed. If you do not yet: that is stated plainly.
- [ ] Cap table and option pool are a table an associate can copy.

## Gate E — Scientific and clinical honesty

For AIxBio, medtech, diagnostics, and therapeutics decks.

- [ ] Intended use is one sentence. Buyer and user are named separately.
- [ ] The experiment or dataset that would falsify the core claim is written down.
- [ ] Hit-rate, sensitivity, or performance numbers include the denominator and the split rule.
- [ ] Anything true only in a demo or a voiceover is labelled as such.

## Gate F — Packet the associate actually scrapes

The visual deck stays human. The leave-behind is what gets parsed.

- [ ] A 2-page text-selectable memo exists alongside the deck.
- [ ] A red-team FAQ exists as its own document, not a slide.
- [ ] Data room has a master index an associate can scan in under 90 seconds.
- [ ] The inbound email is plaintext and lists the attachments in a fixed order: deck, memo, FAQ.
