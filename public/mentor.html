Gatekeeper Checklist

Twenty-four items. Six gates. Twelve minutes.

It scores the failure modes that actually kill a deck in automated screening — flattened charts, missing narrative, and adversarial associate prompts. One point per honest yes.

Gate A

Parser survival

If a number lives only inside a PNG, it does not exist. Selectable text, captions, raw tables, reading order.

Gate B

Numbers a model can extract

TAM / SAM / SOM in a table. Unit economics as numbers, not spark-lines. Ask, post, runway as numerals.

Gate C

Claims vs evidence

Every headline names its source. Regulatory path names the first predicate. Competitive lines name a limit.

Gate D

Red-team FAQ

Moat as a mechanism. COGS contents. CAC or an honest “not yet.” Cap table a model can copy.

Gate E

Scientific honesty

Intended use in one sentence. Falsifying experiment written down. Performance numbers include the denominator.

Gate F

Packet the associate scrapes

2-page memo. FAQ as its own document. 90-second data-room index. Plaintext email with a fixed attachment order.

What your score means

22–24 · Advance

Circulate. Still run a Screen so the hygiene report travels with the deck.

18–21 · Request Data

Do not send yet. Fill the missing tables. Book 30 minutes if two or more Gate E items are no.

The Gatekeeper can already write five reasons to decline. Run the free Screen, then book 30 minutes.
