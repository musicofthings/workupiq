What needs work before you hit send?

Choose a provider, add your API key, and upload your deck. The app saves your key in this browser and uses the local server to send deck text to your chosen provider. Provider usage charges may apply.

First time here? Start the local app

This page needs the WorkupIQ server running on your computer to read files and run reviews. From the project folder, run:

cd local
python3 -m pip install -r requirements.txt
python3 server.py

Then open the local pitch review. If you already have it running, you’re ready to go.
